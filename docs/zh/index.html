怎么用

从一条链接到终端听歌，只需三步。

下载即截取

在 /add 填入起止时间（如 1:30），只保存副歌或精选段落。

终端内播放

上下键选歌，空格播放暂停，Tab 切换队列。无需开网页，极低内存占用。

后台常驻

输入 /bg 或 --background 转入后台，专注编码与工作。

界面

基于 Ratatui 构建的纯终端交互界面，键盘操作行云流水。

功能

为追求专注、讨厌臃肿界面的音乐爱好者量身打造。

下载即截取

填入开始与结束时间点。ytcut 直接提取指定片段，无需后续二次裁剪或重新编码损失音质。

免配置工具链

首次运行自动拉取 yt-dlp 与 ffmpeg，严格校验 SHA-256 完整性，后续按需自动更新。

后台播放守护

支持 --background 或 /bg 脱离终端在后台运行。随时用 ytcut stop 控制。

浏览器免密凭据

按 o 在 Chrome、Edge 或 Brave 中登录 YouTube，ytcut 自动读取 Cookie，畅享受限音频。

静默自动更新

补丁版本在每次启动时静默自动安装；当有大版本发布时给出醒目提醒，省心免维护。

系统级音频路由

完美支持 Linux PulseAudio/PipeWire 与 Windows WASAPI，蓝牙耳机或声卡即插即连。

几秒内即可在本地快速运行。

Cargo (Rust)

使用 Cargo 一键编译安装：

cargo install --git https://github.com/khoryz666/ytcut

Nix

通过 Nix flakes 安装：

nix profile install github:khoryz666/ytcut

CLI 命令行快速调用

命令 说明
ytcut 打开交互式终端界面（TUI）
ytcut add <URL> [--start 1:30] [--end 2:00] 直接下载音频，支持指定起止截取时间点
ytcut play [FILES...] [--shuffle] [--background] 播放指定曲目或当前曲库；--background 可常驻后台
ytcut list 列出音乐文件夹下的所有歌曲
ytcut stop 停止常驻在后台的音频播放进程
ytcut update 更新 yt-dlp 工具链与 ytcut 自身程序
