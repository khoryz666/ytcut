功能

拿到一首歌、继续手头工作，所需的一切都在这里。

下载即截取

在 /add 里填入起止时间，ytcut 只保存该片段——无需重编码，音质无损。

免配置工具链

首次运行自动拉取 yt-dlp 与 ffmpeg，校验 SHA-256，并自动保持更新。

后台播放

用 --background 或 /bg 脱离终端运行；用 ytcut stop 停止。

浏览器免密登录

按 o 在 Chrome、Edge 或 Brave 中登录 YouTube，畅听受限音频。

静默自动更新

补丁版本启动时静默安装；小版本与大版本仅提醒你。

系统级音频路由

Linux 走 PulseAudio/PipeWire，Windows 走 WASAPI，蓝牙耳机即插即用。

安装

几秒内即可在本地快速运行。

预编译
下载 Linux .tar.gz · Windows .exe
Cargo
cargo install --git https://github.com/khoryz666/ytcut
Nix
nix profile install github:khoryz666/ytcut

CLI 命令行快速调用

命令 说明
ytcut 打开交互式终端界面（TUI）
ytcut add <URL> [--start 1:30] [--end 2:00] 直接下载音频，支持指定起止截取时间点
ytcut play [FILES...] [--shuffle] [--background] 播放指定曲目或当前曲库；--background 可常驻后台
ytcut list 列出音乐文件夹下的所有歌曲
ytcut stop 停止常驻在后台的音频播放进程
ytcut update 更新 yt-dlp 工具链与 ytcut 自身程序
