Features

Everything you need to grab a track and get back to work.

Trim on download

Set start and end times in /add and ytcut saves only that range — no re-encode, no quality loss.

Self-managing tools

Downloads yt-dlp and ffmpeg on first run, verifies SHA-256 checksums, and keeps them updated.

Background player

Detach with --background or /bg and keep working while it plays; stop it with ytcut stop.

Browser cookie sign-in

Press o to sign into YouTube in Chrome, Edge, or Brave for age-restricted tracks.

Silent auto-updates

Patch releases install silently on startup; minor and major releases notify you instead.

Native audio routing

PulseAudio/PipeWire on Linux, WASAPI on Windows. Bluetooth headphones and default sinks just work.

CLI quick commands

Command Description
ytcut Open the interactive terminal interface
ytcut add <URL> [--start 1:30] [--end 2:00] Download YouTube audio, optionally trimmed to timestamps
ytcut play [FILES...] [--shuffle] [--background] Play your library or specific tracks; detach with --background
ytcut list List all songs in your library folder
ytcut stop Stop the detached background audio player
ytcut update Update yt-dlp tools and ytcut itself
