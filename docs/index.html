How it works

Three steps from link to music in your terminal.

1

Trim on download

Type start and end times in /add to save just the hook, intro, or solo.

2

Play in terminal

Arrow keys to pick, Space to play, Tab for queue. No browser tabs, no RAM hogging.

3

Detach & work

Send to background with /bg or --background. Focus while audio plays.

Interface

A full-featured TUI built with Ratatui, designed for keyboard efficiency.

Features

Built for people who want audio without the friction.

Trim on download

Provide start and end timestamps. ytcut extracts the exact portion cleanly without re-encoding quality loss.

Self-managing tools

On first launch, ytcut fetches yt-dlp and ffmpeg, checks SHA-256 checksums, and keeps them updated automatically.

Background player

Run headless with --background or /bg. Manage playback with ytcut stop or quick CLI commands.

Browser cookie sign-in

Press o to sign into YouTube in Chrome, Edge, or Brave. ytcut safely reads cookies for age-restricted tracks.

Silent auto-updates

Patch updates apply silently on startup; notifications alert you when minor or major updates arrive.

Native audio routing

PulseAudio/PipeWire on Linux and WASAPI on Windows. Bluetooth headphones and default sinks just work.

Install & quick start

Get ytcut running in seconds.

Prebuilt binaries

Unpack and run:

Latest release Linux (x86-64) & Windows (.exe)

Cargo (Rust)

Build from source with cargo:

cargo install --git https://github.com/khoryz666/ytcut

Nix

Install via Nix flakes:

nix profile install github:khoryz666/ytcut

CLI quick commands

Command Description
ytcut Open the interactive terminal interface
ytcut add <URL> [--start 1:30] [--end 2:00] Download YouTube audio, optionally trimmed to timestamps
ytcut play [FILES...] [--shuffle] [--background] Play your library or specific tracks; detach with --background
ytcut list List all songs in your library folder
ytcut stop Stop the detached background audio player
ytcut update Update yt-dlp tools and ytcut itself
